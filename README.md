# 💻 Emi-Site

Este projeto é um portfólio pessoal e foi desenvolvido com o objetivo de praticar e aprimorar habilidades em desenvolvimento web. Ele serve como uma vitrine para os meus projetos e como um espaço para experimentar novas tecnologias e técnicas de front-end.

---

### Tecnologias Utilizadas

O projeto foi construído com as seguintes linguagens e ferramentas, conforme visível na estrutura de arquivos e análise de linguagens:

* **HTML:** Para estruturar o conteúdo da página web.
* **CSS:** Para estilizar o layout, cores e a interface do usuário.
* **JavaScript:** Para adicionar interatividade e funcionalidades dinâmicas ao site.
* **Front-end Framework/Biblioteca:** A estrutura do projeto sugere o uso de um framework ou biblioteca para otimizar o desenvolvimento.

---

### Como Visualizar

O projeto está hospedado no GitHub Pages, o que facilita a visualização.

**Versão online:**
* Você pode acessar a versão ao vivo do site aqui: **https://emi-fernandes.github.io/emi-site/**

**Visualização local:**
1.  Clone este repositório: `https://github.com/emi-fernandes/emi-site`
2.  Navegue até o diretório do projeto.
3.  Abra o arquivo `index.html` diretamente no seu navegador.
